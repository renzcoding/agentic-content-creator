# Agentic AI Content Creator

An AI-powered content creation system built with Python and local LLMs.

## Features

- Niche planning
- AI script generation
- Automated script quality checks
- Automatic script revision
- Local LLM integration through Ollama

## Tech Stack

- Python
- Ollama
- Qwen 2.5
- Git

## Getting Started

### 1. Install dependencies

Activate your virtual environment and install the required packages.

### 2. Run the application

```bash
python main.py
